## Overview

### Design Philosophy
The KTDA OSHA System frontend is built on **professional simplicity** with **intuitive functionality**. Our design system prioritizes:

- **Clarity over Complexity**: Clean, uncluttered interfaces that focus on user tasks
- **Consistency**: Unified experience across all modules and user roles
- **Accessibility**: WCAG 2.1 AA compliance for inclusive design
- **Efficiency**: Streamlined workflows that reduce cognitive load
- **Safety First**: Visual design that emphasizes safety-critical information

### Technology Stack Summary
- **Framework**: Blazor Server-Side (.NET 8.0)
- **UI Library**: Velzon Bootstrap Admin Template Components
- **Admin Theme**: Velzon Bootstrap Admin Template
- **CSS Framework**: Bootstrap 5.3+ with Velzon styling and KTDA customizations
- **Illustrations**: unDraw.co illustration library
- **Icons**: Bootstrap Icons + Tabler Icons + Remix Icons (Velzon default)
- **Charts**: Chart.js for data visualization

### Target Users & Devices
- **Primary Users**: Factory managers, OSH officers, committee members
- **Secondary Users**: Regional managers, system administrators
- **Device Support**: Desktop (primary), tablets (field use)
- **Browser Support**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+

##### Safety Status Card
```razor
@* Custom safety status card component using Bootstrap *@
<div class="card @GetStatusClass()" style="border-left: 4px solid @GetStatusColor();">
    <div class="card-header d-flex justify-content-between align-items-center">
        <div class="d-flex align-items-center gap-2">
            <i class="@GetStatusIcon() @GetStatusIconColor()"></i>
            <h6 class="card-title mb-0">@Title</h6>
        </div>
        <span class="badge @GetBadgeColor()">@Status</span>
    </div>
    <div class="card-body">

    </div>

@code {
    [Parameter] public string Title { get; set; }
    [Parameter] public SafetyStatus Status { get; set; }
    [Parameter] public RenderFragment ChildContent { get; set; }

    private string GetStatusClass() => Status switch
    {
        SafetyStatus.Compliant => "safety-compliant",
        SafetyStatus.Warning => "safety-warning",
        SafetyStatus.Critical => "safety-critical",
        _ => "safety-unknown"
    };

    private string GetStatusIcon() => Status switch
    {
        SafetyStatus.Compliant => "ri-check-circle-line",
        SafetyStatus.Warning => "ri-alert-line",
        SafetyStatus.Critical => "ri-error-warning-line",
        _ => "ri-question-line"
    };

    private string GetStatusIconColor() => Status switch
    {
        SafetyStatus.Compliant => "text-success",
        SafetyStatus.Warning => "text-warning",
        SafetyStatus.Critical => "text-danger",
        _ => "text-muted"
    };

    private string GetBadgeColor() => Status switch
    {
        SafetyStatus.Compliant => "bg-success",
        SafetyStatus.Warning => "bg-warning",
        SafetyStatus.Critical => "bg-danger",
        _ => "bg-secondary"
    };
}
```

##### Compliance Progress Bar
```razor
@* Custom compliance progress component using Bootstrap *@
<div class="compliance-progress">
    <div class="d-flex justify-content-between align-items-center mb-2">
        <span class="fw-medium">@Label</span>
        <small class="text-muted">@Value/@Total</small>
    </div>
    <div class="progress">
        <div class="progress-bar @GetProgressColor()"
             role="progressbar"
             style="width: @(ProgressPercentage)%"
             aria-valuenow="@Value"
             aria-valuemin="0"
             aria-valuemax="@Total">
        </div>
    </div>
    <small class="text-muted mt-1">@Description</small>
</div>

@code {
    [Parameter] public string Label { get; set; }
    [Parameter] public int Value { get; set; }
    [Parameter] public int Total { get; set; }
    [Parameter] public string Description { get; set; }

    private double ProgressPercentage => Total > 0 ? (double)Value / Total * 100 : 0;

    private string GetProgressColor() => ProgressPercentage switch
    {
        >= 90 => "bg-success",
        >= 70 => "bg-warning",
        _ => "bg-danger"
    };
}
```

### Breadcrumb Implementation
```csharp
// Breadcrumb service for consistent navigation
public class BreadcrumbService
{
    private readonly List<BreadcrumbItem> _breadcrumbs = new();

    public void SetBreadcrumbs(params (string Text, string Href)[] items)
    {
        _breadcrumbs.Clear();
        _breadcrumbs.Add(new BreadcrumbItem("Home", "/", false));

        foreach (var (text, href) in items)
        {
            _breadcrumbs.Add(new BreadcrumbItem(text, href, false));
        }

        if (_breadcrumbs.Count > 1)
            _breadcrumbs.Last().Disabled = true;
    }

    public IReadOnlyList<BreadcrumbItem> GetBreadcrumbs() => _breadcrumbs.AsReadOnly();
}
```

    protected override async Task OnInitializedAsync()
    {
        await LoadDataAsync();
    }

    {
        if (Title != _previousTitle)

            _previousTitle = Title;
        }
    }

        await OnValueChanged.InvokeAsync(value);
        StateHasChanged();

        _isLoading = true;
        // Load data logic
