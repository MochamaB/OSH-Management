## 1. Executive Summary

### What We're Building

A comprehensive Team Management system that allows users to:
- Create teams of various types (OSH Committee, Risk Assessment, Investigation, Custom)
- Assign employees as team members with specific roles
- Validate team composition against business rules
- Manage team lifecycle (Active → Inactive → Disbanded)
- View team details and member assignments
- Edit teams and manage membership changes

### Key Features

✅ **Multi-step Wizard for Team Creation** (using existing VerticalFormWizard component)
✅ **Scope-Aware Member Selection** (users only see employees in their scope)
✅ **Real-time Composition Validation** (ensure teams meet requirements)
✅ **Team Type Configurations** (OSH Committee, Risk Assessment, Investigation)
✅ **Member Management** (add/remove members, change roles, track tenure)
✅ **Integration Ready** (links to Incident, Hazard, CommitteeIssue modules)

### Success Criteria

1. Station managers can create a team with members in under 5 minutes
2. System prevents creation of teams that don't meet composition rules
3. Team members can view their team assignments in employee profile
4. Teams integrate seamlessly with Incident, Risk Assessment, and Committee modules
5. Scope filtering prevents unauthorized access to teams outside user's scope

## 2. System Overview

### Team Hierarchy in Organization

```
Organization
  └── Station (e.g., "Kericho Factory")
      └── Teams
          ├── OSH Committee (1 per station, mandatory)
          │   ├── Chairman (1)
          │   ├── Secretary (1)
          │   ├── Management Reps (2+)
          │   └── Worker Reps (2+)
          │
          ├── Risk Assessment Teams (multiple, per area/process)
          │   ├── Team Leader (1)
          │   ├── Safety Expert (1)
          │   └── Process Experts (2+)
          │
          ├── Investigation Teams (created as needed)
          │   ├── Lead Investigator (1)
          │   ├── Safety Officer (1)
          │   └── Area Supervisor/Observer (1+)
          │
          └── Custom Teams (flexible)
              └── User-defined roles
```

### Team Lifecycle States

```
Draft/Formation → Active → Inactive (temporary) → Disbanded (permanent)
                    ↓
              [Can be reactivated]
```

### Design Principles

1. **Generic Team Model**: One entity serves all team types (discriminated by `TeamType` field)
2. **Type-Specific Configs**: Each team type has optional configuration table (one-to-one)
3. **Composition Validation**: Business rules enforced at creation and modification
4. **Soft Deletes**: Members marked inactive (maintains history), teams disbanded (not deleted)
5. **Scope Filtering**: Users only interact with teams in their authorized scope

## 4. Team Types and Business Rules

### 4.1 OSH Committee

**Purpose**: Mandatory workplace safety committee per OSHA 2007 Section 9

**Composition Rules:**
- Minimum 4 members (typical: 6-12)
- MUST have exactly 1 Chairman
- MUST have exactly 1 Secretary
- MUST have at least 2 Management Representatives
- MUST have at least 2 Worker Representatives
- For multi-section stations: RequiresSectionRepresentation = TRUE

**Validation Logic:**
```csharp
public ValidationResult ValidateOSHCommittee(Team team)
{
    var members = team.TeamMembers.Where(tm => tm.IsActive).ToList();
    var errors = new List<string>();

    if (members.Count < 4)
        errors.Add("OSH Committee requires minimum 4 members");

    var chairmanCount = members.Count(m => m.MemberRole == "Chairman");
    if (chairmanCount != 1)
        errors.Add($"Must have exactly 1 Chairman (found {chairmanCount})");

    var secretaryCount = members.Count(m => m.MemberRole == "Secretary");
    if (secretaryCount != 1)
        errors.Add($"Must have exactly 1 Secretary (found {secretaryCount})");

    var mgmtReps = members.Count(m => m.MemberRole == "Management Rep");
    if (mgmtReps < 2)
        errors.Add($"Must have at least 2 Management Reps (found {mgmtReps})");

    var workerReps = members.Count(m => m.MemberRole == "Worker Rep");
    if (workerReps < 2)
        errors.Add($"Must have at least 2 Worker Reps (found {workerReps})");

    if (team.RequiresSectionRepresentation)
    {
        var sectionsRepresented = members.Where(m => m.SectionId.HasValue)
            .Select(m => m.SectionId.Value).Distinct().Count();
        var totalSections = GetTotalSectionsForStation(team.StationId);

        if (sectionsRepresented < 2)
            errors.Add("Committee must have members from at least 2 different sections");
    }

    return new ValidationResult
    {
        IsValid = !errors.Any(),
        Errors = errors
    };
}
```

**Standard Member Roles:**
- Chairman
- Secretary
- Management Rep
- Worker Rep
- Safety Officer (can overlap with Secretary)

### 4.2 Risk Assessment Team

**Purpose**: Conduct Hazard Identification and Risk Assessment (HIRA)

**Composition Rules:**
- Minimum 3 members
- MUST have exactly 1 Team Leader
- MUST have at least 1 Safety Expert
- MUST have at least 1 Process Expert
- No maximum limit

**Validation Logic:**

### 4.3 Investigation Team

**Purpose**: Investigate accidents, incidents, and near-misses

**Composition Rules:**
- Minimum 3 members (varies by incident severity)
- MUST have exactly 1 Lead Investigator
- MUST have at least 1 Safety Officer
- For serious incidents: MUST have Independent Observer

**Validation Logic:**
```csharp
public ValidationResult ValidateInvestigationTeam(Team team)
{
    var members = team.TeamMembers.Where(tm => tm.IsActive).ToList();
    var config = team.IncidentInvestigationConfig;
    var errors = new List<string>();

    if (members.Count < 3)
        errors.Add("Investigation Team requires minimum 3 members");

    var leadInvestigatorCount = members.Count(m => m.MemberRole == "Lead Investigator");
    if (leadInvestigatorCount != 1)
        errors.Add($"Must have exactly 1 Lead Investigator (found {leadInvestigatorCount})");

    var safetyOfficers = members.Count(m => m.MemberRole == "Safety Officer");
    if (safetyOfficers < 1)
        errors.Add("Must have at least 1 Safety Officer");

    // Check for independent observer if serious incident
    if (config?.EscalationThreshold == "Fatality" || config?.EscalationThreshold == "Major Injury")
    {
        var independentObserver = members.Any(m => m.MemberRole == "Independent Observer");
        if (!independentObserver)
            errors.Add("Serious incidents require an Independent Observer");
    }

    return new ValidationResult
    {
        IsValid = !errors.Any(),
        Errors = errors
    };
}
```

**Standard Member Roles:**
- Lead Investigator
- Safety Officer
- Area Supervisor
- Independent Observer
- Technical Expert

[HttpPost]
[ValidateAntiForgeryToken]
public async Task<IActionResult> Create(CreateTeamViewModel model)
{
    if (!ModelState.IsValid)
    {
        // Reload wizard with errors
        return View(BuildWizardWithErrors(model));
    }

    // 1. Validate team composition
    var validationResult = await _teamService.ValidateTeamCompositionAsync(model);
    if (!validationResult.IsValid && !model.SaveAsDraft)
    {
        foreach (var error in validationResult.Errors)
            ModelState.AddModelError("", error);

        return View(BuildWizardWithErrors(model));
    }

    // 2. Check for duplicate team name in station
    var exists = await _context.Teams
        .AnyAsync(t => t.StationId == model.StationId &&
                      t.TeamName == model.TeamName);
    if (exists)
    {
        ModelState.AddModelError("TeamName", "A team with this name already exists in this station.");
        return View(BuildWizardWithErrors(model));
    }

    // 3. Create Team
    var team = new Team
    {
        StationId = model.StationId,
        TeamType = model.TeamType,
        TeamName = model.TeamName,
        TeamDescription = model.TeamDescription,
        RequiredMemberCount = model.RequiredMemberCount,
        MaxMemberCount = model.MaxMemberCount,
        RequiresSectionRepresentation = model.RequiresSectionRepresentation,
        TeamStatus = model.SaveAsDraft ? "Inactive" : "Active",
        FormationDate = model.FormationDate,
        CreatedAt = DateTime.UtcNow
    };

    _context.Teams.Add(team);
    await _context.SaveChangesAsync();

    // 4. Create type-specific config
    await CreateTeamConfigAsync(team.TeamId, model);

    // 5. Add members
    foreach (var memberDto in model.Members)
    {
        var teamMember = new TeamMember
        {
            TeamId = team.TeamId,
            EmployeePayroll = memberDto.EmployeePayroll,
            MemberRole = memberDto.MemberRole,
            SectionId = memberDto.SectionId,
            EducationLevel = memberDto.EducationLevel,
            RelevantExperience = memberDto.RelevantExperience,
            AppointmentDate = memberDto.AppointmentDate ?? team.FormationDate,
            IsVotingMember = memberDto.IsVotingMember,
            IsActive = true,
            CreatedAt = DateTime.UtcNow
        };

        _context.TeamMembers.Add(teamMember);
    }

    await _context.SaveChangesAsync();

    var statusText = model.SaveAsDraft ? "saved as draft" : "created successfully";
    TempData["Success"] = $"Team '{team.TeamName}' {statusText} with {model.Members.Count} member(s).";

    return RedirectToAction(nameof(Details), new { id = team.TeamId });
}

private async Task CreateTeamConfigAsync(int teamId, CreateTeamViewModel model)
{
    switch (model.TeamType)
    {
        case "OSH Committee":
            _context.OshCommitteeConfigs.Add(new OshCommitteeConfig
            {
                TeamId = teamId,
                IsCommitteeTrained = model.IsCommitteeTrained,
                TrainingDate = model.TrainingDate,
                HasMeetingSchedule = model.HasMeetingSchedule,
                InspectionFrequency = model.InspectionFrequency,
                NextInspectionDate = model.NextInspectionDate,
                CreatedAt = DateTime.UtcNow
            });
            break;

        case "Risk Assessment":
            _context.RiskAssessmentConfigs.Add(new RiskAssessmentConfig
            {
                TeamId = teamId,
                AssessmentFrequency = model.AssessmentFrequency,
                TeamQualifications = model.TeamQualifications,
                NextAssessmentDate = model.NextAssessmentDate,
                CreatedAt = DateTime.UtcNow
            });
            break;

        case "Investigation":
            _context.IncidentInvestigationConfigs.Add(new IncidentInvestigationConfig
            {
                TeamId = teamId,
                InvestigationScope = model.InvestigationScope,
                TeamExpertise = model.TeamExpertise,
                ResponseTimeHours = model.ResponseTimeHours,
                EscalationThreshold = model.EscalationThreshold,
                CreatedAt = DateTime.UtcNow
            });
            break;
    }

    await _context.SaveChangesAsync();
}

public async Task<IActionResult> Index(string? search, string? teamType, int? stationId, string? status)
{
    // Apply scope filter first
    var query = _context.Teams
        .Include(t => t.Station)
        .Include(t => t.TeamMembers.Where(tm => tm.IsActive))
        .AsQueryable();

    query = _scopeFilterService.ApplyScope(query, CurrentScope);

    // Apply filters
    if (!string.IsNullOrEmpty(teamType))
        query = query.Where(t => t.TeamType == teamType);

    if (stationId.HasValue)
        query = query.Where(t => t.StationId == stationId);

    if (!string.IsNullOrEmpty(status))
        query = query.Where(t => t.TeamStatus == status);

    if (!string.IsNullOrEmpty(search))
    {
        query = query.Where(t => t.TeamName.Contains(search) ||
                                 t.TeamMembers.Any(tm => tm.EmployeePayroll.Contains(search)));
    }

    var teams = await query
        .OrderByDescending(t => t.CreatedAt)
        .ToListAsync();

    // Map to ViewModels
    var viewModels = teams.Select(t => new TeamViewModel
    {
        TeamId = t.TeamId,
        TeamName = t.TeamName,
        TeamType = t.TeamType,
        StationName = t.Station.StationName,
        ActiveMemberCount = t.TeamMembers.Count(tm => tm.IsActive),
        MaxMemberCount = t.MaxMemberCount,
        TeamStatus = t.TeamStatus,
        FormationDate = t.FormationDate
    }).ToList();

    // Build DataTable config
    var tableConfig = BuildTeamTableConfig(viewModels);

    return View(tableConfig);
}

public async Task<IActionResult> Details(int id)
{
    var team = await _context.Teams
        .Include(t => t.Station)
        .Include(t => t.TeamMembers.Where(tm => tm.IsActive))
            .ThenInclude(tm => tm.Section)
        .Include(t => t.OshCommitteeConfig)
        .Include(t => t.RiskAssessmentConfig)
        .Include(t => t.IncidentInvestigationConfig)
        .FirstOrDefaultAsync(t => t.TeamId == id);

    if (team == null)
        return NotFound();

    // Check scope access
    if (!await _teamService.HasAccessToTeamAsync(team.TeamId, CurrentScope))
        return Forbid();

    // Get employee details for members
    var payrollNumbers = team.TeamMembers.Select(tm => tm.EmployeePayroll).ToList();
    var employees = await _context.Employees
        .Where(e => payrollNumbers.Contains(e.PayrollNo))
        .ToDictionary(e => e.PayrollNo);

    // Build ViewModel
    var model = new TeamDetailsViewModel
    {
        Team = team,
        Members = team.TeamMembers.Select(tm => new TeamMemberDetailViewModel
        {
            MemberId = tm.MemberId,
            EmployeePayroll = tm.EmployeePayroll,
            EmployeeName = employees.ContainsKey(tm.EmployeePayroll)
                ? $"{employees[tm.EmployeePayroll].FirstName} {employees[tm.EmployeePayroll].LastName}"
                : tm.EmployeePayroll,
            Designation = employees.ContainsKey(tm.EmployeePayroll)
                ? employees[tm.EmployeePayroll].Designation
                : null,
            MemberRole = tm.MemberRole,
            SectionName = tm.Section?.SectionName,
            AppointmentDate = tm.AppointmentDate,
            IsVotingMember = tm.IsVotingMember,
            EducationLevel = tm.EducationLevel,
            RelevantExperience = tm.RelevantExperience
        }).ToList(),
        CompositionStatus = await _teamService.GetCompositionStatusAsync(team)
    };

    return View(model);
}

### 5.4 DELETE - Disband Team

**Approach**: Soft delete (set Status = "Disbanded", set DisbandDate)

**Pre-conditions:**
- Team must not have active linked records (open incidents, active risk assessments, open committee issues)
- Only Station+ scope users can disband
- System roles (OSH Committee) require additional confirmation

**Controller Implementation:**

```csharp
[HttpPost]
[ValidateAntiForgeryToken]
public async Task<IActionResult> Disband(int id, string? reason)
{
    var team = await _context.Teams
        .Include(t => t.TeamMembers.Where(tm => tm.IsActive))
        .Include(t => t.CommitteeIssues.Where(ci => ci.IssueStatus != "Closed"))
        .Include(t => t.Hazards)
        .FirstOrDefaultAsync(t => t.TeamId == id);

    if (team == null)
        return NotFound();

    // Check for active dependencies
    if (team.CommitteeIssues.Any())
    {
        TempData["Error"] = $"Cannot disband team: {team.CommitteeIssues.Count} open committee issue(s).";
        return RedirectToAction(nameof(Details), new { id });
    }

    // Check for active investigations
    var activeInvestigations = await _context.IncidentInvestigations
        .Where(inv => inv.InvestigationTeamId == id &&
                     inv.InvestigationStatus != "Completed")
        .CountAsync();

    if (activeInvestigations > 0)
    {
        TempData["Error"] = $"Cannot disband team: {activeInvestigations} active investigation(s).";
        return RedirectToAction(nameof(Details), new { id });
    }

    // Disband team
    team.TeamStatus = "Disbanded";
    team.DisbandDate = DateTime.UtcNow;
    team.UpdatedAt = DateTime.UtcNow;

    // Deactivate all members
    foreach (var member in team.TeamMembers)
    {
        member.IsActive = false;
        member.DepartureDate = team.DisbandDate;
        member.UpdatedAt = DateTime.UtcNow;
    }

    await _context.SaveChangesAsync();

    _logger.LogInformation($"Team {id} disbanded by {User.Identity.Name}. Reason: {reason}");

    TempData["Success"] = "Team disbanded successfully.";
    return RedirectToAction(nameof(Index));
}
```
