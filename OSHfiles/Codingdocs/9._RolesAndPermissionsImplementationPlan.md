### Phase 3: Employee Role Assignment (Priority: HIGH)
**Estimated Time**: 4-5 hours

#### 3.1 Update Employee Create/Edit

**Changes to `EmployeeController.cs`**:

```csharp
// Existing Create GET - ADD role dropdown population
public async Task<IActionResult> Create()
{
    await PopulateDropdowns();

    // ADD: Load available roles
    ViewBag.AvailableRoles = await _context.Roles
        .Where(r => r.IsActive)
        .OrderBy(r => r.ScopeLevel)
        .Select(r => new { r.RoleId, r.RoleName, r.Description })
        .ToListAsync();

    return View();
}

// Existing Create POST - MODIFY to handle roles
[HttpPost]
public async Task<IActionResult> Create(EmployeeViewModel model, List<int>? SelectedRoles)
{
    // ... existing employee creation code ...

    // MODIFY: Role assignment logic
    if (SelectedRoles != null && SelectedRoles.Any())
    {
        // Assign selected roles
        foreach (var roleId in SelectedRoles)
        {
            _context.EmployeeRoles.Add(new EmployeeRole
            {
                EmployeeId = employee.EmployeeId,
                RoleId = roleId,
                IsActive = true,
                AssignedAt = DateTime.UtcNow,
                AssignedBy = CurrentPayrollNo // From ScopedController
            });
        }
    }
    else
    {
        // Keep existing default "Employee" role assignment
        var defaultRole = await _context.Roles
            .FirstOrDefaultAsync(r => r.RoleName == "Employee" && r.IsActive);

        if (defaultRole != null)
        {
            _context.EmployeeRoles.Add(new EmployeeRole
            {
                EmployeeId = employee.EmployeeId,
                RoleId = defaultRole.RoleId,
                IsActive = true,
                AssignedAt = DateTime.UtcNow,
                AssignedBy = "SYSTEM"
            });
        }
    }

    await _context.SaveChangesAsync();

    return RedirectToAction(nameof(Index));
}

// Similar changes to Edit GET and POST
```

Admin Dashboard
    └── Administration > Roles Management

        │   ├── Create Role → Create Form → Save → Index

## Database Changes

### Required Updates

#### 1. Add AssignedBy to EmployeeRoles

**Migration needed**:
```sql
ALTER TABLE EmployeeRoles
ADD AssignedBy NVARCHAR(50) NULL;
```

This tracks who assigned the role for audit purposes.

#### 2. Create Audit Table (Optional but Recommended)

```sql
CREATE TABLE RoleAssignmentAudit (
    AuditId INT IDENTITY(1,1) PRIMARY KEY,
    EmployeeId INT NOT NULL,
    RoleId INT NOT NULL,
    Action NVARCHAR(20) NOT NULL, -- 'Assigned', 'Deactivated', 'Removed'
    ActionBy NVARCHAR(50) NOT NULL,
    ActionAt DATETIME NOT NULL DEFAULT GETUTCDATE(),
    Reason NVARCHAR(500) NULL,
    FOREIGN KEY (EmployeeId) REFERENCES Employees(EmployeeId),
    FOREIGN KEY (RoleId) REFERENCES Roles(RoleId)
);
```

## Notes

- **Scope Changes**: When a user's roles change, they must **logout and login** for scope to refresh (scope is cached in authentication cookie)
- **System Roles**: Cannot be deleted, role name cannot be changed (Admin, Employee)
- **Default Role**: "Employee" role is auto-assigned if no roles selected during employee creation
- **Permissions**: Follow naming convention "Module.Action" (e.g., "Employee.Create", "Incident.Read")
- **Authorization Policies**: Will be implemented in a later phase using `[Authorize(Policy = "Permission.Name")]`
