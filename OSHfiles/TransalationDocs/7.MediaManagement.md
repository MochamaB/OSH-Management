# Media Management System Design

## Overview
The Media Management module provides a unified, framework-agnostic interface for handling file uploads, storage, retrieval, and management across all OSHA system modules. Inspired by Laravel Spatie's media library but designed for ASP.NET Core implementation, this system serves as a centralized document and media handling service that can be accessed by any module through a consistent interface.

## Design Philosophy
The media management system follows these core principles:
- **Module Independence**: Each OSHA module can use media services without tight coupling
- **Storage Abstraction**: Support multiple storage providers (local, cloud, hybrid)
- **Type Safety**: Strongly-typed interfaces for ASP.NET Core integration
- **Scalability**: Handle large volumes of files with efficient storage and retrieval
- **Security**: Role-based access control and secure file handling
- **Versioning**: Document version control and history tracking
- **Compliance**: Audit trails and retention policy enforcement

## Database Table Design

### **1. Media Collections Table**
**Purpose**: Define logical groupings of media files by purpose and module
**Structure**:
- `collection_id` (Primary Key - Auto-increment)
- `collection_name` (Text - Unique collection identifier)
- `collection_display_name` (Text - Human-readable name)
- `module_name` (Text - Which OSHA module owns this collection)

**Collection Categories**:
- `description` (Text - Purpose and usage of collection)
- `max_file_size_mb` (Integer - Maximum file size allowed)
- `allowed_file_types` (JSON - Array of allowed MIME types)
- `retention_policy_days` (Integer - How long files are kept, null = permanent)

**Access Control**:
- `is_public` (Boolean - Whether files are publicly accessible)
- `requires_authentication` (Boolean - Whether login is required)
- `allowed_roles` (JSON - Array of roles that can access this collection)

**Audit Fields**:
- `created_at` (DateTime - Collection creation timestamp)
- `updated_at` (DateTime - Last update timestamp)
- `created_by_payroll` (Employee payroll - Who created the collection)

**Constraints**:
- Unique: `collection_name` (system-wide unique collection names)

**Example Collections**:
```json
{
  "collection_name": "osh_policy_documents",
  "module_name": "OSH_Policy",
  "allowed_file_types": ["application/pdf", "application/msword"],
  "max_file_size_mb": 10,
  "retention_policy_days": null
}
```

### **2. Media Files Table**
**Purpose**: Core media file metadata and storage information
**Structure**:
- `media_id` (Primary Key - Auto-increment)
- `collection_id` (Foreign Key to media_collections)

**File Identification**:
- `original_filename` (Text - Original uploaded filename)
- `system_filename` (Text - System-generated unique filename)
- `file_hash` (Text - SHA-256 hash for duplicate detection)
- `mime_type` (Text - File MIME type)

**File Properties**:
- `file_size_bytes` (BigInteger - File size in bytes)
- `file_extension` (Text - File extension)
- `file_path` (Text - Storage path/URL)
- `storage_provider` (Text - Local/AzureBlob/AWSS3/etc.)

**File Metadata**:
- `title` (Text - User-friendly file title)
- `description` (Text - File description)
- `alt_text` (Text - Alternative text for accessibility)
- `custom_properties` (JSON - Additional metadata)

**Version Control**:
- `version_number` (Integer - Version of this file)
- `parent_media_id` (Foreign Key - References previous version)
- `is_latest_version` (Boolean - Whether this is the current version)

**File Status**:
- `upload_status` (Text - Uploading/Processing/Complete/Failed)
- `is_active` (Boolean - Whether file is active)
- `processing_status` (Text - For files requiring processing)

**Audit Fields**:
- `uploaded_at` (DateTime - Upload completion timestamp)
- `updated_at` (DateTime - Last update timestamp)
- `uploaded_by_payroll` (Employee payroll - Who uploaded the file)

**Constraints**:
- Foreign Key: `collection_id` references `media_collections(collection_id)`
- Foreign Key: `parent_media_id` references `media_files(media_id)`
- Foreign Key: `uploaded_by_payroll` references `employees(payroll_no)`
- Unique: `file_hash` + `collection_id` (prevent duplicates per collection)

### **3. Media Associations Table**
**Purpose**: Link media files to specific records across all OSHA modules
**Structure**:
- `association_id` (Primary Key - Auto-increment)
- `media_id` (Foreign Key to media_files)

**Association Information**:
- `associated_table` (Text - Table name the media is linked to)
- `associated_record_id` (Text - Primary key of the linked record)
- `association_type` (Text - Type of relationship)

**Association Metadata**:
- `association_label` (Text - User-friendly label for this association)
- `display_order` (Integer - Order for displaying multiple files)
- `is_primary` (Boolean - Whether this is the primary file for the record)

**Association Rules**:
- `is_required` (Boolean - Whether this association is mandatory)
- `max_files_allowed` (Integer - Maximum files for this association type)

**Audit Fields**:
- `created_at` (DateTime - Association creation timestamp)
- `updated_at` (DateTime - Last update timestamp)
- `created_by_payroll` (Employee payroll - Who created the association)

**Constraints**:
- Foreign Key: `media_id` references `media_files(media_id)`
- Foreign Key: `created_by_payroll` references `employees(payroll_no)`
- Unique: `media_id` + `associated_table` + `associated_record_id` + `association_type`

**Example Associations**:
```json
{
  "associated_table": "osh_policies",
  "associated_record_id": "123",
  "association_type": "policy_document",
  "max_files_allowed": 1
}
```

### **4. Media Access Logs Table**
**Purpose**: Audit trail for media file access and operations
**Structure**:
- `access_log_id` (Primary Key - Auto-increment)
- `media_id` (Foreign Key to media_files)

**Access Information**:
- `action_type` (Text - View/Download/Upload/Update/Delete)
- `access_timestamp` (DateTime - When action occurred)
- `user_payroll` (Foreign Key to employees - Who performed action)

**Access Context**:
- `ip_address` (Text - User's IP address)
- `user_agent` (Text - Browser/client information)
- `referrer_url` (Text - Where request came from)

**Request Details**:
- `request_status` (Text - Success/Failed/Unauthorized)
- `response_size_bytes` (Integer - Size of response)
- `response_time_ms` (Integer - Processing time)

**Security Information**:
- `authentication_method` (Text - How user was authenticated)
- `authorization_result` (Text - Access control decision)

**Constraints**:
- Foreign Key: `media_id` references `media_files(media_id)`
- Foreign Key: `user_payroll` references `employees(payroll_no)`

### **5. Media Conversion Jobs Table**
**Purpose**: Track file processing and conversion tasks
**Structure**:
- `job_id` (Primary Key - Auto-increment)
- `media_id` (Foreign Key to media_files)

**Job Information**:
- `job_type` (Text - Thumbnail/Preview/PDF_Conversion/Virus_Scan)
- `job_status` (Text - Pending/Processing/Complete/Failed)
- `started_at` (DateTime - Job start time)
- `completed_at` (DateTime - Job completion time)

**Job Configuration**:
- `job_parameters` (JSON - Configuration for the conversion)
- `priority_level` (Integer - Job priority 1-5)
- `retry_count` (Integer - Number of retry attempts)

**Job Results**:
- `output_media_id` (Foreign Key to media_files - Generated file)
- `error_message` (Text - Error details if failed)
- `processing_notes` (Text - Additional processing information)

**Constraints**:
- Foreign Key: `media_id` references `media_files(media_id)`
- Foreign Key: `output_media_id` references `media_files(media_id)`

### **Service Implementation**

#### MediaService Implementation
```csharp
public class MediaService : IMediaService
{
    private readonly IMediaRepository _mediaRepository;
    private readonly IStorageProvider _storageProvider;
    private readonly ILogger<MediaService> _logger;
    private readonly MediaConfiguration _config;

    public async Task<MediaFile> UploadAsync(IFormFile file, string collectionName, MediaUploadOptions options = null)
    {
        // Validation
        var collection = await _mediaRepository.GetCollectionByNameAsync(collectionName);
        ValidateFile(file, collection);

        // Generate unique filename and hash
        var systemFilename = GenerateUniqueFilename(file.FileName);
        var fileHash = await ComputeFileHashAsync(file.OpenReadStream());

        // Check for duplicates
        var existingFile = await _mediaRepository.GetByHashAsync(fileHash, collection.CollectionId);
        if (existingFile != null && options?.AllowDuplicates != true)
        {
            return existingFile;
        }

        // Store file
        var filePath = await _storageProvider.StoreAsync(file.OpenReadStream(), systemFilename, file.ContentType);

        // Create media record
        var mediaFile = new MediaFile
        {
            CollectionId = collection.CollectionId,
            OriginalFilename = file.FileName,
            SystemFilename = systemFilename,
            FileHash = fileHash,
            MimeType = file.ContentType,
            FileSizeBytes = file.Length,
            FileExtension = Path.GetExtension(file.FileName),
            FilePath = filePath,
            StorageProvider = _storageProvider.ProviderName,
            Title = options?.Title ?? file.FileName,
            Description = options?.Description,
            UploadStatus = "Complete",
            IsActive = true,
            VersionNumber = 1,
            IsLatestVersion = true,
            UploadedAt = DateTime.UtcNow,
            UpdatedAt = DateTime.UtcNow,
            UploadedByPayroll = options?.UploadedByPayroll
        };

        return await _mediaRepository.CreateAsync(mediaFile);
    }

    // Additional service methods...
}
```

## Module Integration Patterns

### **Generic Helper Extensions**
```csharp
public static class MediaExtensions
{
    public static async Task<MediaFile> AddDocumentAsync<T>(this T entity, IFormFile file, string associationType, IMediaService mediaService) where T : class
    {
        var tableName = typeof(T).Name.ToLower();
        var recordId = GetEntityId(entity);

        var mediaFile = await mediaService.UploadAsync(file, $"{tableName}_documents");
        await mediaService.AssociateAsync(mediaFile.MediaId, tableName, recordId, associationType);

        return mediaFile;
    }

    public static async Task<IEnumerable<MediaFile>> GetDocumentsAsync<T>(this T entity, string associationType, IMediaService mediaService) where T : class
    {
        var tableName = typeof(T).Name.ToLower();
        var recordId = GetEntityId(entity);

        return await mediaService.GetByAssociationAsync(tableName, recordId, associationType);
    }
}
```

## Storage Provider Implementations

### **Local Storage Provider**
```csharp
public class LocalStorageProvider : IStorageProvider
{
    private readonly string _basePath;

    public async Task<string> StoreAsync(Stream fileStream, string fileName, string contentType)
    {
        var relativePath = GenerateStoragePath(fileName);
        var fullPath = Path.Combine(_basePath, relativePath);

        Directory.CreateDirectory(Path.GetDirectoryName(fullPath));

        using var fileStream = new FileStream(fullPath, FileMode.Create);
        await fileStream.CopyToAsync(fileStream);

        return relativePath;
    }
}
```

### **Azure Blob Storage Provider**
```csharp
public class AzureBlobStorageProvider : IStorageProvider
{
    private readonly BlobServiceClient _blobServiceClient;
    private readonly string _containerName;

    public async Task<string> StoreAsync(Stream fileStream, string fileName, string contentType)
    {
        var blobName = GenerateBlobName(fileName);
        var containerClient = _blobServiceClient.GetBlobContainerClient(_containerName);
        var blobClient = containerClient.GetBlobClient(blobName);

        await blobClient.UploadAsync(fileStream, new BlobHttpHeaders { ContentType = contentType });

        return blobName;
    }
}
```

## Security and Access Control

### **Permission-Based Access**
```csharp
public class MediaAuthorizationHandler : AuthorizationHandler<MediaAccessRequirement, MediaFile>
{
    protected override Task HandleRequirementAsync(AuthorizationHandlerContext context, MediaAccessRequirement requirement, MediaFile resource)
    {
        var user = context.User;
        var userRoles = user.Claims.Where(c => c.Type == ClaimTypes.Role).Select(c => c.Value);
        var userStation = user.Claims.FirstOrDefault(c => c.Type == "StationId")?.Value;

        // Check collection-level permissions
        var allowedRoles = JsonSerializer.Deserialize<string[]>(resource.Collection.AllowedRoles);
        if (!allowedRoles.Any(role => userRoles.Contains(role)))
        {
            context.Fail();
            return Task.CompletedTask;
        }

        // Check station-level access for station-specific files
        var associations = GetFileAssociations(resource.MediaId);
        if (associations.Any(a => RequiresStationAccess(a) && !HasStationAccess(userStation, a)))
        {
            context.Fail();
            return Task.CompletedTask;
        }

        context.Succeed(requirement);
        return Task.CompletedTask;
    }
}
```

## API Controller Implementation

### **MediaController**
```csharp
[ApiController]
[Route("api/[controller]")]
public class MediaController : ControllerBase
{
    private readonly IMediaService _mediaService;

    [HttpPost("upload/{collectionName}")]
    public async Task<ActionResult<MediaFileDto>> Upload(string collectionName, IFormFile file, [FromForm] MediaUploadDto uploadDto)
    {
        var options = new MediaUploadOptions
        {
            Title = uploadDto.Title,
            Description = uploadDto.Description,
            UploadedByPayroll = User.GetPayrollNumber()
        };

        var mediaFile = await _mediaService.UploadAsync(file, collectionName, options);
        return Ok(MapToDto(mediaFile));
    }

    [HttpGet("{mediaId}")]
    public async Task<ActionResult> Download(int mediaId)
    {
        var mediaFile = await _mediaService.GetByIdAsync(mediaId);
        if (mediaFile == null) return NotFound();

        var stream = await _mediaService.GetFileStreamAsync(mediaId);
        return File(stream, mediaFile.MimeType, mediaFile.OriginalFilename);
    }

    [HttpPost("{mediaId}/associate")]
    public async Task<ActionResult> Associate(int mediaId, [FromBody] MediaAssociationDto associationDto)
    {
        var result = await _mediaService.AssociateAsync(mediaId, associationDto.TableName, associationDto.RecordId, associationDto.AssociationType);
        return result ? Ok() : BadRequest();
    }
}
```

## Performance Optimization

### **Caching Strategy**
- **File Metadata Caching**: Cache frequently accessed media file metadata
- **Collection Configuration Caching**: Cache collection settings to avoid database hits
- **Storage Provider Caching**: Implement CDN for public files
- **Thumbnail Caching**: Pre-generate and cache image thumbnails

### **Database Optimization**
- **Indexing**: Proper indexing on file_hash, association keys, and access patterns
- **Partitioning**: Partition large tables by date or collection
- **Archive Strategy**: Move old files to archive storage based on retention policies

## Compliance and Audit Features

### **Audit Trail**
- Complete access logging for all file operations
- Retention policy enforcement with automated cleanup
- Version history maintenance for document control
- Digital signature support for critical documents

### **Regulatory Compliance**
- GDPR compliance with data deletion capabilities
- Kenyan data protection law compliance
- Industry-specific retention policies
- Secure file handling for sensitive documents

This media management system provides a robust, scalable foundation for handling all document and file requirements across the OSHA system while maintaining security, compliance, and performance standards suitable for ASP.NET Core implementation.
